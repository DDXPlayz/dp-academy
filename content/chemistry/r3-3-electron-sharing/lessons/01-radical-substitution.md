## Radicals

A **radical** has an unpaired electron. Because it seeks to pair that electron, it is **highly reactive**.

```figure
src: chemistry/_iitian/ib-dp-chemistry-r3-3-2-homolytic-fission-study-notes/img/fig-d8504784fd9fc499.png
caption: Homolytic fission: the bond pair splits evenly, one electron to each atom, giving two radicals (shown with single-headed arrows).
```

```figure
src: chemistry/_iitian/ib-dp-chemistry-r3-3-1-radicals-study-notes/img/fig-b55b6bbef703a9c6.png
caption: UV light splits a chlorine molecule homolytically into two chlorine radicals.
```

```figure
src: chemistry/_iitian/ib-dp-chemistry-r3-3-2-homolytic-fission-study-notes/img/fig-3ddd52a18578a65c.png
caption: Initiation: UV light breaks Cl-Cl to form two chlorine radicals.
```

Radicals form by **homolytic fission**, typically of a weak bond such as Cl–Cl, using **UV light** (or heat):

$$
\text{Cl}_2 \xrightarrow{\text{UV}} 2\text{Cl}\bullet
$$

## Radical substitution of methane

Alkanes are unreactive (strong, non-polar C–H bonds), but they react with chlorine or bromine in UV light.

```figure
src: chemistry/_iitian/ib-dp-chemistry-r3-3-3-substitution-reactions-with-alkanes-s/img/fig-bb064a2107379608.png
caption: Propagation step 1: a chlorine radical takes a hydrogen from methane, forming HCl and a methyl radical.
```

```figure
src: chemistry/_iitian/ib-dp-chemistry-r3-3-3-substitution-reactions-with-alkanes-s/img/fig-9e172329312deac2.png
caption: Propagation step 2: the methyl radical takes a chlorine atom from Cl₂, forming chloromethane and a new chlorine radical.
```

```figure
src: chemistry/_iitian/ib-dp-chemistry-r3-3-3-substitution-reactions-with-alkanes-s/img/fig-a86db795851dacfc.png
caption: Termination: two radicals combine, removing radicals from the chain.
```

```keyidea
Initiation makes radicals. Propagation steps each use one radical and produce another, so the chain keeps going. Termination joins two radicals and removes them.
```

**Initiation:**
$\text{Cl}_2 \rightarrow 2\text{Cl}\bullet$

**Propagation:**
$\text{CH}_4 + \text{Cl}\bullet \rightarrow \text{CH}_3\bullet + \text{HCl}$
$\text{CH}_3\bullet + \text{Cl}_2 \rightarrow \text{CH}_3\text{Cl} + \text{Cl}\bullet$

**Termination:**
$\text{Cl}\bullet + \text{Cl}\bullet \rightarrow \text{Cl}_2$
$\text{CH}_3\bullet + \text{Cl}\bullet \rightarrow \text{CH}_3\text{Cl}$
$\text{CH}_3\bullet + \text{CH}_3\bullet \rightarrow \text{C}_2\text{H}_6$

## A mixture of products

Cl• can also attack CH₃Cl, giving CH₂Cl₂, then CHCl₃ and CCl₄ (**further substitution**). Termination also makes ethane. With longer alkanes, any hydrogen can be substituted, giving structural isomers. So radical substitution gives a **mixture** that must be separated.

```figure
src: chemistry/_iitian/ib-dp-chemistry-r3-3-3-substitution-reactions-with-alkanes-s/img/fig-162764f73079d43b.png
caption: Further substitution: chlorine radicals keep replacing hydrogens, giving di-, tri- and tetrachloromethane.
```

```figure
src: chemistry/_sme/electron-sharing-reactions/img/fig-9bbb47ede33c12fb.png
caption: Hexane and bromine react in sunlight (the colour disappears) but not in the dark: UV light is needed to start the radical reaction.
```

```example
C₂H₅• + Br₂ → C₂H₅Br + Br•
```

## Summary

- Radicals have an unpaired electron; formed by homolytic fission in UV light.
- Initiation → propagation (chain) → termination.
- Products are a mixture because of further substitution and different possible positions.
