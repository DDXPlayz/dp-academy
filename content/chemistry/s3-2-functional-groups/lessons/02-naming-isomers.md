## Naming in four steps

1. Find the **longest carbon chain** containing the functional group → stem (meth-, eth-, prop-, but-, pent-, hex-).
2. Add the **suffix** for the main functional group (-ane, -ene, -ol, -al, -one, -oic acid…).
3. **Number** the chain to give the functional group the lowest number.
4. Add **substituents** as prefixes (methyl-, ethyl-, chloro-, bromo-…) in alphabetical order with locants.

```example
Name CH₃CH(CH₃)CH₂CH₂OH and CH₃CHClCH(CH₃)CH₃.
---
Longest chain with –OH: 4 C; OH on C1; methyl on C3 → 3-methylbutan-1-ol.

Longest chain: 4 C; number to give lowest locants: chloro on C2, methyl on C3 → 2-chloro-3-methylbutane.
```

## Primary, secondary, tertiary

| Class | Carbon bearing the group is bonded to… | Alcohol example |
|---|---|---|
| Primary (1°) | one other C | butan-1-ol |
| Secondary (2°) | two other C | butan-2-ol |
| Tertiary (3°) | three other C | 2-methylpropan-2-ol |

(For amines, the classification counts carbons bonded to the nitrogen.)

## Structural isomers

```keyidea
Structural isomers share a molecular formula but differ in how the atoms are connected. They can differ in chain (branching), position of the functional group, or class of functional group.
```

| Type | Example (same formula) |
|---|---|
| Chain | butane / 2-methylpropane (C₄H₁₀) |
| Position | propan-1-ol / propan-2-ol (C₃H₈O) |
| Functional group | propanal / propanone (C₃H₆O); ethanol / methoxymethane (C₂H₆O) |

```example
Draw the structural isomers of C₅H₁₂.
---
Pentane CH₃CH₂CH₂CH₂CH₃; 2-methylbutane CH₃CH(CH₃)CH₂CH₃; 2,2-dimethylpropane C(CH₃)₄. Three isomers.
```

## Summary

- Longest chain → suffix → lowest locants → alphabetical prefixes.
- 1°, 2°, 3° by the number of carbons attached to the functional-group carbon.
- Structural isomers: chain, position, functional group.
